# NOVA --- Responsive Architecture Landing Page

A clean, modern landing page for **NOVA --- Urban Architecture Studio**,
built as part of the DecodeLabs Frontend Development training program.
This project builds on the static landing page from Project 1 and
focuses on making the layout responsive using CSS.

## 📌 Project Overview

The goal of this project was to adapt the existing landing page for
different screen sizes while maintaining a consistent visual style,
readable content, and clear layout.

## ✨ Features

-   Responsive landing-page layout for desktop, tablet, and mobile
    screens
-   Architecture-inspired visual design with a warm, minimal color
    palette
-   Hero section with a headline, description, and call-to-action
-   Studio statistics section
-   Selected-spaces project cards
-   Featured project section
-   Navigation and footer
-   CSS media queries for responsive adjustments
-   Semantic HTML structure and accessible image alternative text

## 🛠️ Built With

-   **HTML5** --- page structure and semantic elements
-   **CSS3** --- styling, layout, and responsive behavior
-   **CSS Grid & Flexbox** --- page and component layouts
-   **Media Queries** --- adapting the layout to different viewport
    sizes

> This project focuses on HTML and CSS. JavaScript and backend
> functionality are not required for this static landing page.

## 🧩 Page Sections

1.  **Header & Navigation** --- NOVA branding and main navigation
2.  **Hero** --- primary heading, introduction, and featured
    architectural visual
3.  **Studio Stats** --- project, city, and experience figures
4.  **Selected Spaces** --- residential, workplace, and cultural project
    cards
5.  **Featured Project** --- CASA TERRA feature with image and
    description
6.  **Footer** --- studio information and contact details

## 🚀 Run Locally

1.  Clone or download this repository.
2.  Open the project folder in your code editor.
3.  Open `index.html` in your browser.

No package installation or build command is required for this static
HTML/CSS project.

## 📱 Responsive Design

The page uses CSS to adjust layout, spacing, images, and content
presentation for smaller screens. Test it at desktop, tablet, and mobile
widths using your browser's responsive design tools.

## ✅ Quality Checklist

-   [ ] Navigation and section links work as intended
-   [ ] Content remains readable at mobile widths
-   [ ] Images include meaningful `alt` text
-   [ ] Images have explicit `width` and `height` attributes
-   [ ] CSS is maintained in an external stylesheet
-   [ ] HTML passes the [W3C Markup
    Validator](https://validator.w3.org/)
-   [ ] Layout is checked with Lighthouse in Chrome DevTools
